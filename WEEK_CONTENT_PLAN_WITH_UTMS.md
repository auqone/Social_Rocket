## UTM TRACKING GUIDE

### What Each Parameter Means:
- **utm_source**: Which platform (linkedin, facebook, twitter)
- **utm_medium**: Always "social" for social media posts
- **utm_campaign**: "week1_features" - groups all week 1 posts together
- **utm_content**: Specific post ID (monday_post1, tuesday_post2, etc.)

### How to Track in Google Analytics:
1. Go to **Acquisition → All Traffic → Source/Medium**
2. Filter by "social" medium
3. Click into each source to see which specific posts (utm_content) drove traffic
4. Track conversions/signups by source

### Best Performing Posts:
After 1 week, check which utm_content values drove most:
- Traffic
- Time on site
- Signups
- Feature usage

Then create more content like those winners!
